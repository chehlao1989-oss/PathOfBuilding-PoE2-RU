# Сайт русской PoB 2

Публичный адрес: https://chehlao1989-oss.github.io/PathOfBuilding-PoE2-RU/

Дизайн «Атлас» выбран владельцем 18 ноября 2026 года. Сайт — статические HTML, CSS и JavaScript без сборщика и внешних библиотек. GitHub Pages публикует каталог `/docs` ветки `ru-release`. `.nojekyll` отключает обработку Jekyll. Основная программа и архивы выпуска не зависят от сайта.

## Файлы

- `index.html` — тексты, ссылки на выпуск, метаданные и структурированные данные SoftwareApplication.
- `site-assets/site.css` — оформление, адаптация к узким экранам и настройки доступности.
- `site-assets/site.js` — переключение трёх скриншотов и просмотр в диалоге. Скачивание, установка, ссылки и ответы на вопросы доступны без JavaScript.
- `images/tree-build-ru.png` — присланный владельцем Screenshot_58.png, готовый билд с характеристиками, 1916×1028. Используется на главной странице, при увеличении и в Open Graph. Файл публикуется без изменения; видимая версия дерева 0_4 и предупреждение программы сохранены.
- `images/import-ru.jpg`, `images/trade-compare.png` — реальные скриншоты импорта и торговли. Прежний `images/tree-ru.png` сохранён для README и ранних материалов.
- `sitemap.xml` — карта сайта с каноническим адресом.

## При новом выпуске

Сохранять метатег `google-site-verification` в `<head>` главной страницы: он добавлен по коду, предоставленному владельцем для Google Search Console. Публикация метатега — отдельный шаг; подтверждение ресурса и отправка Sitemap выполняются в аккаунте владельца.

1. Сверить поддерживаемые версии PoB и игры с `localization/release.json`, README и отчётом QA. Не обещать совместимость с будущей игрой до отдельной проверки.
2. В `index.html` обновить обе ссылки скачивания ZIP, ссылки на страницу выпуска, подписи версии и размера, а также `softwareVersion` и `downloadUrl` в JSON-LD.
3. При изменении интерфейса обновить реальные скриншоты и их подписи. Не публиковать авторизацию, личные билды или ответы API.
4. Обновить дату `lastmod` в `sitemap.xml`.
5. Проверить навигацию, галерею, закрытие диалога, FAQ, мобильную ширину, скачивание и внешние ссылки. После push проверить завершение Pages и публичную страницу.

Название страницы, описание, канонический URL, Open Graph и JSON-LD помогают поисковикам понять страницу. Индексация и позиция в поиске не гарантируются; Search Console требует отдельной настройки владельцем. Проектный `robots.txt` не добавлен: у GitHub Pages этого вида правила robots читаются из корня домена, а сайт размещён в подпапке.

Сайт не содержит упоминаний инструмента разработки, аналитики, форм авторизации и донатов. Форумный пост и обращение к разработчикам PoB при публикации сайта не меняются.
