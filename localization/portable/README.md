# Русская PoB для PoE 2

**Выпуск v0.23.1-ru.1-beta.5 · PoB 0.23.1 · данные PoE 2 0.5.5g**

Запустите **Path of Building-PoE2.exe** из распакованной папки. Русский язык включён по умолчанию. Переключение — **Настройки → Язык**. Билды и настройки появятся рядом с программой, в `Builds` и `Settings.xml`.

Для импорта кода откройте **Импорт / экспорт**. Для собственного персонажа выполните авторизацию на сайте Path of Exile, выберите персонажа, импортируйте дерево и самоцветы, затем предметы и умения. Сохраните результат отдельной сборкой.

Поиск улучшений — **Предметы → Найти эти предметы на рынке → Подбор**. Выберите своё главное умение и задайте бюджет и максимальный уровень. Наведение на предложение показывает сравнение. Кнопка **Импорт** добавляет и экипирует найденную вещь в PoB. Прежнюю вещь можно вернуть через список соответствующей ячейки экипировки.

Это бета-выпуск. Текущее дерево, видимые активные умения, камни поддержки и основные каталоги предметов переведены. Известные исключения — 17 скрытых эффектов монстров, две скрытые базы Energy Blade, часть исторического дерева 0_4 и отдельные исходные ограничения PoB. Подробности находятся в `docs/QA-RU.md` и `coverage`.

Программа проверяет русские выпуски при запуске и каждые 12 часов. Нажмите «Обновления» или Ctrl+U для ручной проверки, в том числе при переходе с beta 3 или beta 4. Когда появится «Обновить PoB», нажмите её и подтвердите скачивание. После проверки архива сохраните билд и закройте старую PoB. Новая версия скопирует Builds, Settings.xml и imgui.ini, затем откроется из соседней папки. Старую папку можно использовать для отката. Если запускаете PoB ярлыком, укажите в нём новую папку.

Переход с beta 1 и beta 2: сохраните билд и закройте PoB, распакуйте beta 5 в новую папку, до первого запуска скопируйте Builds и Settings.xml из прежней сборки. Старую папку оставьте для отката.

Что изменилось в beta 5: прогресс скачивания и явные этапы установщика, перевод подсказок выбора характеристики, перенос длинных уведомлений. Версии PoB и данных не изменились; исправления beta 4 сохранены.

Индикатор показывает установщик исходной версии. При обычном переходе из публичной beta 4 процент ещё не появится. Новый установщик есть внутри beta 5 для следующих обновлений. Для теста индикатора на 4 → 5 используйте отдельную тестовую beta 4 с новым EXE установщика и его config, как описано в Release на GitHub.
